# Security Policy

## Supported versions

Security fixes are provided for the latest released version of PDF Builder. Users should reproduce an issue on the latest version before submitting a report when possible.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected vulnerability. Email [develop@mpdigitals.com](mailto:develop@mpdigitals.com) with:

- the affected PDF Builder version;
- the Salesforce environment and relevant configuration;
- reproduction steps or a minimal proof of concept;
- the expected and actual behavior;
- the potential impact; and
- any suggested mitigation, if available.

Do not include credentials, session identifiers, private keys, access tokens, or customer data. Use synthetic data and redact sensitive identifiers.

The report will be acknowledged within five business days. The maintainers will investigate, request additional information when needed, and coordinate remediation and disclosure. Please allow a reasonable remediation period before publishing details.

For general support and non-security bugs, use GitHub Issues or email `develop@mpdigitals.com`.
